# Развёртывание проектов

Утилита на Python и Tkinter создаёт стартовые проекты по пресетам. Укажите название,
выберите шаблон и родительский каталог. Имя папки по умолчанию следует за названием
проекта. Ручное изменение отключает автозаполнение, кнопка **Как название** включает его снова.

## Запуск

Из каталога `projectDeployer` выполните `python main.py`.
Нужны Python 3.11+ с Tkinter и Git 2.28+. Для React-пресета рекомендуется Node.js 24 LTS с npm
и нужен доступ к реестру пакетов. В Debian/Ubuntu для системного Python обычно нужны
пакеты `python3-tk` и `python3-venv`.

Чтобы выбрать отдельный интерпретатор для создания Python-проектов, задайте
`PROJECT_DEPLOYER_PYTHON` с путём к нему. В текущей облачной Linux-среде
можно использовать системный Tk для отображения кириллицы и Python из PATH
для создания виртуального окружения:

```sh
PROJECT_DEPLOYER_PYTHON="$(command -v python3)" /usr/bin/python3 main.py
```

- **Python** создаёт `.venv`, стартовый `main.py`, тест на `unittest`, README и `.gitignore`.
- **React + Vite + TypeScript** использует официальный `create-vite@9.3.4` с пресетом
  `react-ts`, устанавливает зависимости и сохраняет `package-lock.json`. Имя npm-пакета
  берётся из латинских букв и цифр названия, а для полностью кириллического названия
  используется `project`. Имя папки при этом остаётся таким, каким его указали в форме.

Оба пресета инициализируют Git с начальной веткой `main`. Первый коммит выполняется
вручную. Шпаргалка видна до создания проекта и сохраняется в `CHEATSHEET.md`.
Существующие папки защищены от перезаписи. Если шаг завершится ошибкой после
создания папки, журнал покажет причину и путь к частичному проекту.

## Добавление шаблона

Скопируйте папку одного из примеров из `templates/` и измените её содержимое.
При следующем запуске утилита подхватит шаблон. Пользовательские шаблоны можно
хранить отдельно от установки, в подкаталоге `ProjectDeployer/templates`:

- Windows — в `%APPDATA%`
- macOS — в `~/Library/Application Support`
- Linux — в `$XDG_CONFIG_HOME` или `~/.config`

В каждой папке шаблона разместите `template.json` и каталог `files/` с
обязательной шпаргалкой `CHEATSHEET.md` и остальными файлами будущего проекта.

```json
{
  "name": "Мой шаблон",
  "description": "Описание и требования",
  "commands": [],
  "post_commands": [
    {"label": "Проверка", "args": ["python", "check.py"]}
  ]
}
```

Каждый элемент `args` передаётся как отдельный аргумент. Команды выполняются в новом
каталоге проекта. Сначала выполняется `commands`, затем копируется `files/`, потом
выполняется `post_commands`. В примере `check.py` лежит в `files/`. Оба списка
команд можно опустить. Используйте шаблоны из доверенных источников, поскольку
указанные в них команды запускаются от вашего имени.

Доступные переменные в аргументах и UTF-8-файлах:

- `{{project_name}}` — название из формы.
- `{{folder_name}}` — имя папки из формы.
- `{{package_name}}` — имя, пригодное для npm.
- `{{project_name_json}}` — название в виде JSON-строки с кавычками и экранированием.

В Windows команды через `.cmd` и `.bat` принимают только простые аргументы.
Для свободного текста передавайте аргументы напрямую в исполняемый файл, например Python.

## Проверка

В каталоге `projectDeployer` выполните:

```sh
python -m unittest discover -s tests -v
```

Для GUI-проверок в Linux без рабочего стола запустите эту команду через
`xvfb-run -a`. Полный прогон использует Python, Git, Node.js, npm и доступ к реестру npm.

## Упаковка в Windows EXE

На Windows из каталога `projectDeployer`:

```powershell
py -m pip install pyinstaller
py -m PyInstaller --onefile --windowed --name ProjectDeployer --add-data "templates:templates" main.py
```

EXE будет находиться в `dist`. Для создания проектов из EXE инструменты выбранного
пресета (Python для Python-проекта, Node.js с npm для React-проекта и Git) должны
быть установлены и доступны через PATH.
