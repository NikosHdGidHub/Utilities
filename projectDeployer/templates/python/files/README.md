Консольное приложение на Python 3.11+. Нужны Python с venv и Git.
В PowerShell запустите `.\.venv\Scripts\Activate.ps1`, затем

Точка входа — `main.py`, зависимости перечислены в `requirements.txt`.
Окружение хранится в `.venv/`. [Шпаргалка](CHEATSHEET.md)
